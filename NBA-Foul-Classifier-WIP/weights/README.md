## 2. Why `ebard_basketball_yolo.pt` Replaced Generic COCO `yolo11n.pt`

Generic COCO detectors classify every human in an NBA arena (players, referees, coaches, cameramen, courtside fans) as generic class `0: person` and frequently miss fast-moving basketballs.

**`ebard_basketball_yolo.pt`** (trained directly on NBA broadcast game footage from the Extended Basketball Action Recognition Dataset):
- Explicitly separates **`referee` (class 3)** from active on-court **`player` (class 2)**, stopping referees and spectators from entering the biomechanical feature stream or getting highlighted during annotation.
- Directly detects the **`hoop` (class 1)** and **`basketball` (class 0)** at high recall, enabling accurate on-ball pair anchoring and rim/shooting foul localization.
- Automatically downloads into `weights/ebard_basketball_yolo.pt` on first run via `ensure_ebard_basketball_weights()` in `2_preprocess_tubes.py`.

## 3. Trained Checkpoint Schema (`best_foul_r2plus1d.pt`)

Saved by Stage 4 (`4_train_eval.py` / Notebook Cell 6) after leak-free 5-fold game-grouped validation:
- `architecture`: `"FoulMILEnsemble_Swin3D_v3"` (or `"FoulMILClassifier_Swin3D_v3"` when trained with `--cv-folds 1`)
- `ensemble_state_dicts`: List of all 5 fold models' weights averaged at inference time via `FoulMILEnsemble` to reduce single-fold variance on unseen NBA games.
- `model_state_dict`: Best single fold's trained weights (`visual_proj`, `BiomechanicalFoulEncoder`, `window_fusion`, Gated Attention MIL, `window_foul_head`, real `window_type_head`, `bag_foul_head`) for backward compatibility.
- `temperature`: Global Out-of-Fold (OOF) NLL-minimized temperature scaling parameter $T$ fitted across all unseen-game clips.
- `optimal_threshold`: Global Out-of-Fold (OOF) threshold $\tau$ optimizing composite F1 + Balanced Accuracy across all unseen NBA games.
- `metrics` & `cv_fold_summary`: Global OOF and per-fold `roc_auc`, `f1`, `balanced_accuracy`, `accuracy`, `precision`, `recall`, and `call_type_accuracy`.
